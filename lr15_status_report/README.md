## 1. Головне трьома реченнями

Під час спринту 2 зовнішній API розкладу корпусу B повертав помилку 503 протягом трьох днів, через що інтеграційну історію S-06 не вдалося перевірити і її перенесено на наступний спринт. Водночас команда зняла блокер граничних випадків алгоритму S-04 та завершила історію S-07, закривши 8 SP з 10 запланованих. Для захисту від повторних збоїв розкладу ми розгорнули локальний mock-сервер, зафіксували технічний борг D-03 та зберегли прогнозовану дату завершення релізу з випередженням графіка.
