## 3. Дашборд

Дашборд побудований для замовника від господарської частини (ST-01), який приймає рішення про строки і обсяг релізу. На ньому чотири метрики: cycle time P85 з flow.csv показує швидкість доставки і сигналізує про затор у потоці; прогнозна дата релізу з forecast.csv дає замовнику відповідь на головне питання - чи встигаємо; кількість відкритих ризиків з високим score показує рівень загрози проєкту; обсяг технічного боргу pay_now з techdebt.csv показує розробнику, скільки роботи треба зробити до релізу.

Метрика, яку я свідомо не поставив, і чому: velocity (points за спринт) - бо при двох спринтах вибірка замала для висновків, і при тиску на velocity команда надуває оцінки замість прискорення доставки (слайд 7 лекції L8).
