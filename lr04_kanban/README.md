## 1. Definition of Workflow

| Колонка | Картка потрапляє сюди, коли | Картка виходить звідси, коли |
| --- | --- | --- |
| Backlog | Вимога або задача зафіксована у вигляді чорновика. | Є чітке розуміння, як реалізувати задачу, і вона потрібна в найближчі дні. |
| Ready | Зрозуміло, що вважається її завершенням, і вона розбита до розміру 1-2 днів роботи. | Картку взято в активну розробку, ліміт In Progress дозволяє це. |
| In progress | Фактично розпочато написання тексту, коду або аналіз. | Отримано перший цілісний результат (чорновик документа або написаний шматок коду). |
| Review | Результат можна прочитати, відкрити або протестувати. | Перевірка успішна, зауваження виправлені, критерії якості виконано. |
| Done | Роботу залито в публічний репозиторій або повністю затверджено. | Залишається тут назавжди для історії та підрахунку метрик. |
